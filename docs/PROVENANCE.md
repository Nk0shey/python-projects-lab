# Source provenance

The starting material was supplied by Nikita Kozchenko in `esercitazione3.zip` and `Archive (2).zip`. The archives contain exercises, teaching prompts and student implementations. Four selected works form the basis of this collection:

- `Archive (2).zip` → `lesson 12.11.25.py` → `python_lab/library.py`.
- `esercitazione3.zip` → `ask05.py` → `python_lab/bank.py`.
- `esercitazione3.zip` → `task04.py` → `python_lab/exams.py`.
- `esercitazione3.zip` → `task03.py` → `python_lab/sales.py`.

These files were substantially completed and reorganized. Relevant original function names and assignment algorithms are retained, while persistence, validation, tests and packaging documentation were added. See CHANGES.md and DESIGN.md for the final behavior.

Examples in this repository are fictional and were prepared for demonstrations and tests. Original personal datasets and serialized binary files are not included. The uploaded archives are kept separate from this revised code.

Teaching scaffolds may have separate authorship. No blanket license is assigned without confirming ownership of the original material.
